# South Coast Controls: first-package evaluation

One real order. Traceable changes. SCC engineer review. | 8 November 2026

## Minimum package

1. **Customer-marked PDF:** the returned drawing set, including annotations, handwriting and revision clouds. Keep the original annotation layer where possible.
2. **Matching baseline CAD and PDF:** the exact drawing issue the customer marked. SCC's normal source is DWG; for the current correction path also provide an ASCII DXF export with attributes, units and layouts preserved, plus the plotted PDF. Native DWG conversion/editing is not configured. Identify CAD version, missing fonts, external references and custom/proxy objects.
3. **BOM spreadsheet, if available:** native XLSX or CSV for that same issue. Keep sheet names, part numbers, tags and quantities; do not clean away real formatting problems. If no BOM exists, say so: BOM verification will be untested.

Helpful extras: the relevant specification pages and one example of the required customer drawing style. If available, include the engineer-completed next revision and its BOM separately as a held-out reference for scoring proposed corrections. A revision-comparison demo can use both issues, but is not a blind redesign test.

## Preserve useful context while redacting

Remove restricted customer/site names, addresses, personal information and commercial details. Keep device tags, ratings, dimensions, quantities, sheet numbers, revision sequence and comments. Use consistent aliases across files. Apply real redaction, then check selectable text, annotations, metadata, CAD layers and hidden spreadsheet sheets. Keep the unredacted originals at SCC.

Share only through the agreed named-recipient channel after confirming the handling terms and any NDA. No SCC mailbox connection is needed for this first run.

## What Rivet will return

- One consolidated comment-and-response log in Excel and PDF, with source location, proposed response, uncertainty and recorded status.
- A per-request account of proposed/applied changes, remaining questions and before/after evidence where supported.
- Supported edits in drawing/BOM copies with saved-file rechecks. Preserve the original CAD file structure where supported; explicitly report unsupported objects, layouts, references and incomplete coverage. A review report is not a complete plotted drawing set.
- A short walkthrough and findings summary for SCC engineers. Native EPLAN project editing and unrestricted DWG or engineering redesign are outside the current verified scope; assess EPLAN project/export formats separately.

## How we judge the result

Agree the answer key with SCC. Report comments located and correctly read separately; then changes correctly implemented, missed and incorrectly introduced. Identify which sheets, devices and BOM rows were actually checked. Also report unresolved items, engineer corrections and elapsed processing/review time. Test pass counts and confident wording do not establish engineering accuracy.

On receipt, Rivet first checks readability, dependencies and scope, then confirms the video delivery target. A paid pilot follows only after SCC reviews the real result and both sides agree the supported workflow, acceptance criteria and commercial terms.
